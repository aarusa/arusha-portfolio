Crypto Dash is a simple, interactive cryptocurrency dashboard built to make market information easy to explore. It brings live prices, market movement, and coin details into one clear interface — without the noise.

The goal was a beginner-friendly dashboard that still feels useful for experienced users. Real-time API data powers a responsive grid of coin cards, with filter, sort, and limit controls so you can scan the market quickly and focus on what matters.

Each coin opens into a details view with market rank, AUD pricing, 24h highs and lows, supply data, and a Chart.js price history. Built with React, Vite, and React Router, the app keeps updates smooth while staying readable on any screen.
